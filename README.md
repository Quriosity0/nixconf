Personal **NixOS** configuration built with **flakes**. It covers the whole system (NixOS modules) and the user environment (Home Manager), for a single desktop machine named `asuspc`.

> **Note:** this is a personal configuration. It is published for reference and is not meant to be used as-is on other machines. Feel free to copy pieces of it.

| Area | What is used |

| Kernel | CachyOS kernel, `linuxPackages-cachyos-latest-x86_64-v3` |

| Desktop | GNOME with a curated set of extensions, SDDM display manager (Wayland, custom `echo` theme) |
| Shell | zsh + oh-my-zsh (`ys` theme, `web-search`, `z`, `sudo`, `gpg-agent`) |
| Editors | Neovim (`vi`/`vim` aliases), VS Code (FHS build), OpenIDE, OpenCode |
| Gaming | Steam (with Millennium, Proton-CachyOS, Proton-GE, Protontricks), Prism Launcher, Faugus Launcher |
| Containers / VMs | Podman (DNS enabled), Distrobox, VMware Workstation host, KVM group |
| Communication and media | Discord via Equicord (nixcord), Spotify via Spicetify (Bloom theme), OBS Studio (CUDA), Materialgram |
| Networking | NetworkManager, `proxy-suite` (zapret DPI bypass + local Telegram WS proxy), AmneziaVPN, `mtr` |

## Repository structure

```
nixconf/
├── flake.nix              # Flake entry point: inputs and the `asuspc` NixOS configuration
├── flake.lock             # Pinned versions of all inputs
├── configuration.nix      # System-wide NixOS configuration
├── home.nix               # Home Manager configuration for user `quriosity`
├── hardware-configuration.nix  # Generated by nixos-generate-config (do not edit by hand)
├── modules/
│   ├── default.nix        # Home Manager module index (imports the modules below)
│   ├── nixcord.nix        # Discord client (Equicord) with plugins and QuickCSS
│   ├── spicetify.nix      # Spotify client customization (theme, extensions, snippets)
│   └── proxy-suite.nix    # zapret DPI bypass, tg-ws-proxy, proxy-suite GUI
└── LICENSE                # GPL-3.0
```

### `flake.nix`

Defines one NixOS system, `nixosConfigurations."asuspc"`. It:

- adds the CachyOS kernel overlay, the Millennium overlay and the NUR overlay;
- imports the `proxy-suite` NixOS module and the NUR modules from the `quriosity` repo;
- loads `configuration.nix` and `modules/proxy-suite.nix`;
- integrates Home Manager as a NixOS module (`useGlobalPkgs`, `useUserPackages`), with `home.nix` for user `quriosity` and NUR Home Manager modules as shared modules.

### `configuration.nix`

System settings:

- **Boot:** Limine with the NixOS branding and a 1920x1080 resolution; `v4l2loopback` virtual camera ("OBS Cam"); `ntsync` kernel module; `/tmp` cleaned on boot.
- **Locale:** `en_US.UTF-8` as the default, `ru_RU.UTF-8` for address, measurement, monetary, numeric, paper, time, and other regional categories.
- **Users:** `quriosity` with the `networkmanager`, `wheel` and `kvm` groups, default shell zsh.
- **Hardware:** NVIDIA open driver (`nvidiaPackages.latest`), power management disabled, `nvidia-settings` disabled; `openrazer` for user `quriosity`.
- **Packages:** `wget`, `curl`, `git`, `fastfetch`, `btop`, `gnupg`, `gdu`, `podman-compose`, `podman-tui`, `flameshot`, `zenity`, `tabby` (from NUR).
- **Programs:**
  - Steam with Remote Play and dedicated-server firewall rules opened, Millennium integrated, extra compatibility tools (`proton-cachyos` from NUR, `proton-ge-bin`);
  - AppImage support with binfmt, `nix-ld`, `mtr`, `amnezia-vpn`;
  - zsh with completion, autosuggestions, syntax highlighting, and aliases (see below);
  - Neovim, GnuPG agent with SSH support.
- **Desktop:** SDDM (Wayland, `echo` theme from the `quriosity.sddm-themes` option), GNOME, Flatpak, the X keyboard layout `us`, the `nvidia` video driver, and a set of GNOME apps excluded from the install.
- **Virtualisation:** Podman with DNS enabled, the container stack, and the VMware Workstation host module.
- **Fonts:** DejaVu, JetBrains Mono Nerd Font, Ubuntu Mono Nerd Font, Montserrat Alternates.
- **Nix:** extra substituter `attic.xuyh0120.win/lantian` (for CachyOS kernel binaries), flakes enabled, `nix-path` pointing to the channel and to this `configuration.nix`.
- **Networking:** NetworkManager. The hosts file blocks BattlEye test/production endpoints (a GTA Online fix).

### `home.nix`

User-level configuration:

- **Applications:** Prism Launcher (with Java 8, 17 and 25 runtimes, and ffmpeg), DroidCam, SourceGit, Faugus Launcher, VMware Workstation, Materialgram, HardInfo2, VLC, XnViewMP, Distrobox, OpenCode, uv, Helium and Zen browsers, BedrockNix, OpenIDE, Transmission (GTK), Kvantum.
- **OBS Studio:** built with CUDA and the plugins background removal, PipeWire audio capture, VA-API, GStreamer, Vulkan capture, input overlay, multi-RTMP, and LiveSplit One.
- **VS Code:** the FHS build (`vscode.fhs`).
- **Artcraft Suite:** `photocraft`, `filmcraft`, `pdfcraft`, `wordcraft`, `deckcraft`, `gridcraft`; dark theme, English, close-to-tray, autostart.
- **GNOME:** `gnome-tweaks`, `refine`, and extensions: Blur my Shell, Dash2Dock Lite, Just Perfection, Clipboard Indicator, App Hider, Rounded Window Corners Reborn, Caffeine, Tiling Shell, Status Tray, User Themes. They are enabled through `dconf`.
- **Session variables:** `NIXPKGS_ALLOW_UNFREE=1`, `NIX_PATH` pointing to `configuration.nix`.

### `modules/`

- **`nixcord.nix`:** Equicord for Discord with a large plugin set (message logger, call timers, custom timestamps, Vencord RPC, and others) and a custom QuickCSS.
- **`spicetify.nix`:** Spotify with the `bloom` theme in dark mode, extensions (Full App Display, Shuffle, Adblock, Volume Percentage, Beautiful Lyrics, Sidebar Customizer), many UI snippets, and custom apps (Marketplace, Lyrics Plus, Wavelink).
- **`proxy-suite.nix`:**
  - **zapret (`zapret-discord-youtube` engine, config `general(ALT)`):** a DPI bypass for a list of domains (Discord, YouTube, Spotify, GitHub, Steam, Telegram, and others), with an exclusion list for domestic services and private IP ranges;
  - **tg-ws-proxy:** a local Telegram MTProto WebSocket proxy listening on `127.0.0.1:1080`;
  - **GUI:** proxy-suite GUI with autostart.

  The domain lists are tailored for users in Russia.

## Requirements

- [NixOS](https://nixos.org/) **unstable** with flakes enabled
- An Intel CPU and an NVIDIA GPU, if you want to reuse the hardware-specific settings
- [Home Manager](https://github.com/nix-community/home-manager) (integrated through the flake, no separate install needed)

> **Notes:**
> - Nix flakes are still marked as experimental in some setups. If needed, pass `--experimental-features 'nix-command flakes'` to the rebuild command.
> - Unfree packages are allowed in this configuration (`nixpkgs.config.allowUnfree = true`). The commands below also set `NIXPKGS_ALLOW_UNFREE=1` for the first build.
> - The configuration is tested only with the **official NixOS unstable channel**. Other channels may cause build errors.
> - The NixOS host name must match the flake output name: `asuspc`. The user name is `quriosity`. Both are hard-coded in `flake.nix`, `configuration.nix`, `home.nix`, and in the shell aliases. If you change them, update all these places.

## Installation

```bash
git clone https://github.com/Quriosity0/nixconf.git ~/nixconf
sudo nix-channel --add https://channels.nixos.org/nixos-unstable nixos
sudo nix-channel --add https://github.com/nix-community/home-manager/archive/master.tar.gz home-manager
sudo nix-channel --update
NIXPKGS_ALLOW_UNFREE=1 sudo nixos-rebuild switch --flake ~/nixconf#asuspc
sudo reboot
```

Replace `hardware-configuration.nix` with the output of `nixos-generate-config` for your machine before the first build. The file in this repository belongs to the `asuspc` hardware.

## Updating

After the first install, the `update` alias rebuilds the system and Home Manager configuration:

```bash
update
```

To update the config to the latest commit:

```bash
cd ~/nixconf
git pull
update
```

To update all flake inputs (`flake.lock`) and check the flake:

```bash
flpull   # nix flake update
flchk    # nix flake check
update
```

To remove old generations and free disk space:

```bash
clean-gens
```
