Personal **NixOS** configuration built with **flakes**. It covers the whole system (NixOS modules) and the user environment (Home Manager), for a single desktop machine named `asuspc`.

> **Note:** this is a personal configuration. It is published for reference and is not meant to be used as-is on other machines. Feel free to copy pieces of it.

## Repository structure

### `flake.nix`

Defines one NixOS system, `nixosConfigurations."asuspc"`. It:

- adds the CachyOS kernel overlay, the Millennium overlay and the NUR overlay;
- imports the iNiR and `proxy-suite` NixOS modules and the NUR modules from the `quriosity` repo;
- loads `configuration.nix` and `modules/proxy-suite.nix`;
- integrates Home Manager as a NixOS module (`useGlobalPkgs`, `useUserPackages`), with `home.nix` for user `quriosity` and NUR Home Manager modules as shared modules.

### `configuration.nix`

System settings:

- **Boot:** Limine with the NixOS branding and a 1920x1080 resolution; `v4l2loopback` virtual camera ("OBS Cam"); `ntsync` kernel module; `/tmp` cleaned on boot.
- **Locale:** `en_US.UTF-8` as the default, `ru_RU.UTF-8` for address, measurement, monetary, numeric, paper, time, and other regional categories.
- **Users:** `quriosity` with the `networkmanager`, `wheel` and `kvm` groups, default shell zsh.

- **Packages:** `wget`, `curl`, `git`, `fastfetch`, `btop`, `gnupg`, `gdu`, `podman-compose`, `podman-tui`, `flameshot`, `zenity`, `tabby` (from NUR).
- **Programs:**

  - iNiR and its Niri desktop session
  - AppImage support with binfmt, `nix-ld`, `mtr`, `amnezia-vpn`;
  - zsh with completion, autosuggestions, syntax highlighting, and aliases (see below);
  - Neovim, GnuPG agent with SSH support.
- **Desktop:** SDDM (Wayland, `echo` theme from the `quriosity.sddm-themes` option), Flatpak, the X keyboard layout `us`, and the `nvidia` video driver.

## Requirements

- [NixOS](https://nixos.org/) **unstable** with flakes enabled
- An Intel CPU and an NVIDIA GPU, if you want to reuse the hardware-specific settings
- [Home Manager](https://github.com/nix-community/home-manager) (integrated through the flake, no separate install needed)

> **Notes:**
> - Nix flakes are still marked as experimental in some setups. If needed, pass `--experimental-features 'nix-command flakes'` to the rebuild command.
> - Unfree packages are allowed in this configuration (`nixpkgs.config.allowUnfree = true`). The commands below also set `NIXPKGS_ALLOW_UNFREE=1` for the first build.
> - The configuration is tested only with the **official NixOS unstable channel**. Other channels may cause build errors.
> - The NixOS host name must match the flake output name: `asuspc`. The user name is `quriosity`. Both are hard-coded in `flake.nix`, `configuration.nix`, `home.nix`, and in the shell aliases. If you change them, update all these places.

## Installation

The flake includes iNiR's NixOS module and enables `programs.inir.desktop`. It builds the Hub-capable `inir` CLI from the pinned `snowarch/inir-cli` input and uses `modules/inir-families.nix` to package the requested family plugins into a Nix-managed runtime. The default configuration selects iRiS. This provides iNiR, Niri, and the Niri session; it does not replace GNOME. Do not run iNiR's generic `./setup install` script on this NixOS setup. NixOS support in iNiR is experimental.

```bash
git clone https://github.com/Quriosity0/nixconf.git ~/nixconf
sudo nixos-rebuild switch --flake ~/nixconf#asuspc
sudo reboot
```

Replace `hardware-configuration.nix` with the output of `nixos-generate-config` for your machine before the first build. The file in this repository belongs to the `asuspc` hardware.

After rebooting, choose the **Niri** session in SDDM to start iNiR. GNOME remains available as another session. Choose any combination of supported families in `configuration.nix`:

```bash
programs.inir.families = [ "ii" "waffle" "iris" ];
```

The IDs are `ii` (Material), `waffle`, and `iris` (iRiS). Waffle requires Material, so selecting Waffle automatically includes `ii`. Rebuild after changing the list; all included families can then be selected from iNiR's UI. The family archives and hashes are pinned in `flake.nix`; update those there instead of running `inir hub install`, which cannot write into the Nix store. Home Manager points `~/.local/bin/inir` at the selected Nix package so an older setup-generated link cannot shadow it.

## Updating

After the first install, the `update` alias rebuilds the system and Home Manager configuration:

```bash
update
```

To update only iNiR:

```bash
cd ~/nixconf
nix flake update inir
sudo nixos-rebuild switch --flake ~/nixconf#asuspc
```

To update the config to the latest commit:

```bash
cd ~/nixconf
git pull
update
```

To update all flake inputs (`flake.lock`) and check the flake:

```bash
flpull   # nix flake update
flchk    # nix flake check
update
```

To remove old generations and free disk space:

```bash
clean-gens
```
